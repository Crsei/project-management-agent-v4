# Mobile Companion 设计预览

这是 Dovspace 的移动交互 Demo，不是可工作的移动客户端。固定示例不读取工作区、项目、会话或账号；不调用模型、执行工具、保存业务数据或自动完成任务。它也不是正式 `/pm` 或 Agent 页面在服务不可用时的回退。

## 入口与构建

受控 Lab 中进入 `/lab/pm` 的「Mobile Companion」，或直接访问 `/lab/pm/mobile`。沿用 [Lab 门禁](../../deploy/README.md#生产-web同源-api-与-lab-门禁)：开发操作默认开放，所有普通生产 build 默认关闭；生产 Caddy 始终拒绝 `/lab`，不得为展示关闭这条保护。

需要独立静态预览时，在仓库根目录运行：

```bash
PM_ENABLE_LAB=true node scripts/build-mobile-demo.mjs
```

该命令要求显式启用 Lab，不加载本机 `.env`，使用原 Web Vite 配置及完整来源／许可构建插件，在 `.local/mobile-demo-build-*` 新建隔离产物，不覆盖 `apps/web/dist`、不修改来源清单、不自动部署。输出目录含正常应用入口，以及独立的 `lab/pm/mobile.html`。后者只加载 Demo 和共享字体／主题，CSP 禁止 `connect-src`；不挂载正式业务 Providers，也不创建 Service Worker。

核对未占用的临时端口后，用输出的实际目录替换下方 `BUILD_DIR`：

```bash
DOVSPACE_ISOLATED_CHECKS=1 PM_ENABLE_LAB=true \
pnpm --filter @pm/web exec vite preview --host 127.0.0.1 \
  --port 4487 --strictPort --outDir BUILD_DIR
```

`BUILD_DIR` 应使用绝对路径；打开 `http://127.0.0.1:4487/lab/pm/mobile.html`。这是本机临时预览，不等于公共入口部署，也不能直接从手机访问手机自己的 `127.0.0.1`。不要为了手机预览将真实后端监听到公网；远程访问需要单独设计连接与安全边界。

部署仍需来源校验、受影响检查和当前服务归属核验。独立构建成功不能替代 `node scripts/check-sources.mjs` 或实际发布门禁；有既有来源漂移时保留当前可用服务，不重新采集清单掩盖问题。

## 演示范围

四个主入口为「今日、项目、Agent、我的」。窄屏使用底部导航，宽屏使用侧栏；聊天有独立滚动记录与输入区，短视口收起非必要区域并保留返回入口，不随控件焦点改变布局。主题支持浅色、深色、跟随系统；场景面板可用 Escape 关闭并返回触发按钮。

三条评审路径：

1. **阅读变化**：今日筛选「附件」→ `DEMO-104` 任务→查看变更→阅读／代码视图→标记示例已阅→返回。筛选保留；已阅不改变任务「进行中」状态。
2. **从任务交给 Agent**：任务→引用到 Agent→编辑草稿→预览固定步骤→查看结果与依据样本。引用始终带任务 ID 与 revision r7；样本结果不冒充模型执行或真实测试。
3. **恢复而不重发**：在聊天写草稿→场景设置切换离线→预览重连→核对示例结果。此过程保留草稿与当前脚本进度，不执行发送、不自动推进；「结果未知」仍不声称成功。

真实发送、执行、修改任务、应用补丁、附件上传及危险操作均禁用。附件／引用入口只解释设计或选择固定引用，不能选择本机文件。Agent 步骤由用户明确点击「预览下一步」推进，最多三步；其文字与输入草稿无关，不模拟自动生成回复。

场景设置包括正常、空数据、加载、错误、离线、版本过期、无权限、结果未知和长内容。错误与权限场景是可切换的设计样本，不是服务器响应；恢复按钮只改变本页示例状态。长内容用于评审换行、历史滚动与新内容提示。

## 状态与边界

- 草稿、筛选、任务引用、已阅标记、步骤、主题与场景只存在于当前页面内存；刷新即丢失。「重置演示」统一恢复初始状态，不撤销任何真实操作，因为 Demo 没有这些操作。
- 页面内返回恢复来源页面；这不是持久化路由、深链接或跨设备会话合同。
- Demo 不使用真实工作区 ID、Provider 凭据、文件目录或数据库；不恢复隐藏的交付工作台。
- 无网络请求不代表正式产品已具备离线缓存、重连、同步或幂等写入能力。
- 会话与持久化尚未统一设计收口；当前真实产品仍沿用 Agent Chat 保存方式。本 Demo 的内存状态不构成新的持久化方案。

## 长期建设顺序

本轮止于 T1–T5：信息架构与视觉、移动外壳、PM 阅读、Agent 对话样本、异常状态与隔离交付。它验证交互，不宣称可用于生产。

| 后续阶段 | 建设范围 | 开始接入／验收门槛 |
| --- | --- | --- |
| T6：连接与只读数据 | 明确本机／远程服务身份，接入授权项目、任务与版本阅读 | 先确定支持的部署拓扑、TLS／认证／撤销边界；真实空态、失权、断线及来源版本可核对，不以 Demo 替代失败 |
| T7：真实 Agent 与恢复 | 接入既有 Session、generation、流式记录及工具证据 | PM 与 Agent 身份不混用；历史／新消息滚动稳定；断线先查询原执行结果，不自动重发；会话恢复与草稿保存合同经确认 |
| T8：有限业务写入 | 按场景逐项开放评论、确认或已有授权操作 | 复用应用服务、revision/CAS 与原收据；未知结果先核对；任务完成仍由既有业务规则决定，不由 UI 或 Run 成功推断 |
| T9：设备与分发 | 真机兼容、无障碍、安装／通知等独立决策 | iOS Safari、Android Chrome、键盘、横屏、放大文字、返回手势及网络切换分别验收；再决定是否需要 PWA／原生壳，不先引入 Service Worker 或推送承诺 |

持续评审应使用同一组任务与结果证据，而不是不断增加孤立展示页。复用真实领域服务和现有主题；移动适配留在呈现与交互层，不建立第二套任务状态机或权限体系。

## 评审清单

- 三条路径均能返回来源；筛选、未发送草稿与示例引用按本页合同保留。
- 360／390／430px 及平板宽度无横向正文溢出；深浅主题可辨识；放大文字不遮挡操作。
- 长记录中离开底部后，新步骤不把用户拉回；新内容入口可回到底部。
- 键盘／短视口不遮住输入；面板支持键盘焦点、Escape 和焦点恢复。桌面浏览器模拟视口不能代替真机键盘验收。
- 页面无业务 API、WebSocket、模型调用、浏览器持久化或外部文件读取；刷新与重置符合内存边界。
- 受控预览与默认关闭 Lab 的正式产物分别检查；构建、来源、许可与公共入口部署结果分别记录，不合并成「已可用」。
