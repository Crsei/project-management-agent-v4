# 营销站构建、素材与验证边界

本页描述当前源码的使用方式和已知限制，不代表当前工作树已通过检查、真实供应商账号验收或生产部署。历史计划和本机验收原件保留在本地，不作为公开安装依赖。

## 当前范围

`apps/marketing` 是独立的 Astro 静态站，六个公开路由为首页 `/`、自托管 `/get-started/`、桌面 `/desktop/`、下载与发行状态 `/download/`、套餐与用量规划 `/plans/`、安全与运维 `/security/`。全站统一展示 Dovspace；导航与首屏的“开始使用”进入自托管指南，不是尚未闭合验收的安装包或尚未开放的云套餐。

六个路由共用浅色产品型设计系统；首页以真实产品图、可切换展示、深色工作流、交错能力说明、紧凑 Provider 列表和实际使用入口组织内容，不再连续重复文字卡片。`SiteLayout` 加载 `styles/site.css`，`GuideLayout` 叠加 `styles/guide.css` 的目录与长文排版，下载页单独加载 `styles/download.css`，不另设页面主题。

### 设计 Token 与组件

| 范围 | 统一规则 |
| --- | --- |
| 背景与正文 | `--bg: #ffffff`、`--surface: #f8f9fc`、`--fg: #111827`；正文 `--muted: #526074`，次级文字 `--dim: #5e6878` |
| 品牌与控件 | `--accent: #6851cf`、悬停 `#5741b5`、浅强调底 `#f0edff`；品牌色比参考示例更深，用于保证小字号链接和按钮的对比度 |
| 层次与边界 | 边框 `#e3e7ef`，控件边界 `#8792a5`；控件／卡片／产品图圆角为 8／16／20px，共用产品图柔和阴影 |
| 深色局部 | 工作流和命令块使用 `#131a2b`，正文 `#f8faff`、次级文字 `#bfc8d8`；不把深色扩展成另一个全站主题 |
| 排版与间距 | 内容最大宽度 1240px，区块垂直间距桌面 96px／窄屏 64px；正文 16px，主操作至少 44px 高，指南正文另收窄为可读宽度 |

- `SiteLayout`：页首、资源菜单、移动导航、跳过链接及分组页脚；`GuideLayout`：同主题目录与正文框架。
- `ProductHero`：价值说明、两个真实 CTA 和首屏看板实拍。
- `ProductImage`：统一原比例图片容器、响应式素材、替代说明、真实性标注与原图入口。
- `ProductShowcase`：项目管理／Agent Chat／结果核对三个可访问 Tab，含各自进一步了解入口。
- `WorkflowStory`：定义 Issue → 明确执行目标 → 执行并查看结果 → 回到项目核对的连接式流程及真实读回图。它是操作顺序说明，不是自动执行、模型回放或自动完成承诺。
- `CapabilitySections`、`TrustAndNextSteps`：交错项目／Markdown 展示、紧凑 Provider 状态、部署选择、简洁限制摘要及最终 CTA。

全站保留现有 DM Sans、中文回退字体及 JetBrains Mono，不替换字体、产品标志或截图文件。新的编排参考 Plane 的产品优先和明暗层次、agentes.chat 的场景叙事、Magpie 的紧凑功能展示，不复制三站源码、图片、品牌资产或文案。已有第三方图标与原始视觉来源记录继续按 [LICENSE.t3code](../../LICENSE.t3code) 及随附许可保留，不因重构改授根许可证。

本站产品标志使用用户于 2026-11-15 批准的 Dovspace 矢量重建稿（不带额外翼折扇面），规范源为 [`apps/web/public/dovspace.svg`](../../apps/web/public/dovspace.svg)；这是按所提供验证图重建并获批的资产，不冒充原始设计文件或已注册商标。营销站的 `/dovspace.svg` 与 `/favicon.svg` 同步使用该彩色标志，引用统一带 `?v=20261115` 缓存版本；不滤色、不重绘图形或另加背景。所有页面共用 `SiteLayout` 的页首／页脚，下载页应用图标也使用同一素材；Dovspace 文字及原字体文件保留。文字相邻的图像用空替代文本避免重复朗读，品牌首页链接保留明确的可访问名称；README 直接引用规范源。第三方 Provider 标志、字体、截图及其来源记录不随产品品牌替换，此同步也不关闭原生发行或第三方许可门禁。

P0 文案区分一次性首次设置与原账号登录、PM 与 Agent 身份、文件夹／Session 与 PM 目标、取消与未知结果，以及桌面本地模式／更新器边界。可信本机、单 Agent 操作者不是公网多租户承诺；目录不是沙箱，Run 成功不代表任务完成。会话与持久化仍暂沿用 Agent Chat，统一设计尚未收口。

## 套餐与用量内容边界

`/plans/` 使用 `GuideLayout` 的浅色长文布局，共用全站导航、页脚及指南侧栏入口；首页仅展示精简概要和说明链接，不新增试用、升级、购买或收集表单。

- **当前自托管**：不赠送平台云空间、不套用未来云套餐上限，也不是无限容量承诺。当前是可信本机、单 Agent 操作者工作台，不因成员或未来席位规划变成生产多租户 Agent 平台；会话与持久化仍沿用 Agent Chat，统一设计尚未收口。
- **未来云规划**：订阅按工作区；Free 最多 5 名真人、共享 5 GB 云附件空间、拟免费；Team 按需购席位、最多 50 人、共享 100 GB；Business 按需购席位、最多 200 人、共享 1 TB。Team／Business 价格待成本核算；全部规划中、未生效、不可购买，不承诺 SAML／SSO／SLA。GB／TB 为十进制。
- **计量建议**：有效、未撤销、未禁用的真人在同一工作区去重，管理员计入、跨项目只计一次；待接受邀请不计费，加入／恢复重新核额，Agent 不占席位，不承诺免费访客。区分已用／已购／套餐上限，撤销释放可用席位不等于退款。
- **云附件空间建议**：平台附件及保留版本计入，本地代码、外部 Markdown 与自带存储桶不混计；引用去重、隐藏不释放，当前没有自动 GC。临时上传预占在失败后先核对再释放；80% 提醒、满额拒绝增长但不删数据，降级不删文件。当前单文件 8 MiB 上限独立于未来总容量。
- **费用与状态**：项目／任务不按数量收费是规划，不承诺无限性能；AI 使用自带 Provider 并由供应商计费，不赠送或虚构 AI 额度。正式后端尚未接入订阅与全量计量合同，静态页不展示假成员数、假已用空间，不由缺少订阅数据推断 Free 或自托管；未知用量不显示为 0 或无限。支付返回不等于生效，未来仍以真实服务端权益为准。

这些是公开说明，不启用收费、订阅、限额或新权限体系。营销站不配置或开通工作台服务，也没有可购买的托管商业云；公开 URL 配置与网关保持独立。

## 本地构建与公开变量

在仓库根目录使用已安装的仓库工具链执行：

```sh
pnpm dev:marketing
# 检查和构建由集成人员在修改合并后统一执行
pnpm typecheck:marketing
pnpm build:marketing
pnpm preview:marketing
```

开发和静态预览都绑定 `http://127.0.0.1:4330/`，不要同时占用该端口；`preview` 读取已有的 `apps/marketing/dist/`，不会代替构建。`typecheck` 执行 Astro／TypeScript 检查；`build` 生成该静态产物目录，不重建 PM／Agent／Web 工作台。

Astro 接受有／无尾斜线的请求，站内导航仍统一使用带尾斜线页面地址；这样本地静态预览可直接访问原样随附、没有扩展名的 `/LICENSE`，不会被页面尾斜线守卫错误拒绝。实际静态托管也须保留该文件及其他许可资源的访问。

在 `apps/marketing/.env` 配置以下**公开、构建时**变量，修改后须重新构建；浏览器可见内容不能放访问令牌、Provider 密钥、账号密码或其他秘密。

| 变量 | 默认值与行为 |
| --- | --- |
| `PUBLIC_APP_URL` | 默认 `http://127.0.0.1:3224/pm`；必须是不含嵌入凭据的绝对 HTTP(S) 地址，无效值使构建失败。本地地址显示“打开本地工作台”并说明须先启动服务；它指向访问者自己的机器，不是可供远程客户使用的在线服务。 |
| `PUBLIC_SOURCE_URL` | 默认 `https://github.com/Crsei/project-management-agent-v4`；可覆盖为不含嵌入凭据的实际 HTTPS 地址，无效覆盖值不显示源码入口。仓库首页不是运行成品的对应源码证明。 |

旧 `PUBLIC_WORKSPACE_URL` 已移除，须迁移到 `PUBLIC_APP_URL`。`PUBLIC_DESKTOP_RELEASE_URL` 也已移除：一个任意配置的发行页不能启用下载。发行状态改为下述人工核对的静态清单，不由环境变量或访问页面时的请求决定。

页面各自提供标题与描述，布局输出 description、Open Graph 的站点名／语言／标题／描述，以及 Twitter summary 标题／描述。尚未确定正式宣传站域名，因此不生成 canonical、`og:url` 或虚构分享图地址，也不把本地 4330 地址当成公开元信息；无需设置站点域名变量。

## 产品图与发行材料

首页使用同一隔离合成 Nova 演示数据集的六张真实截图：项目看板、未发送的 Agent Chat 草稿、人工保存后刷新读回的任务详情，各有桌面／移动端实拍。采集没有调用模型，不是 Provider 验收或 Agent 完成任务的证据；图片保持原始比例并提供替代说明、说明文字和原图入口。公开 `/screenshots/SOURCE.json` 记录截图摘要、实际页面、隔离数据与采集限制，另附 PM 源码／运行产物摘要；已有 Web 产物的准确预构建源码身份未知，因此不冒充干净 HEAD 或完整对应源码发行。不能用来源项目截图、隐藏的交付工作台或真实用户业务数据替代。

[发行清单](../../apps/marketing/src/lib/release-inventory.ts)保存有核对日期、公开元数据来源与缺失证据的构建时快照；不是实时更新源，不覆盖私有或草稿材料。当前桌面版本从 `apps/desktop/package.json` 读取，但这是源码声明，不是实际构建身份。历史预发布单独列出平台／架构、摘要、签名和对应提交限制，不能沿用为当前工作树的原生验收；公开摘要的一致性也不等于重新计算过安装器字节。

当前 Windows／macOS 原生安装、启动、升级、卸载保留数据和 GUI 验收未闭合；四项第三方发行门禁仍为 OPEN。安装入口保持无链接、不可聚焦的禁用状态；公开发行页与证据链接仅用于核对，不是安装推荐或发布授权。更新清单需要重新核对准确版本、平台和来源，不能仅改成可点击按钮。

## 响应式与键盘实现

公共布局提供首个键盘入口“跳到主要内容”和可聚焦的 `main`。主要导航优先展示产品、部署方式、套餐与用量；桌面、发行与安全放入原生“文档与资源”菜单，六个路由均有当前页标记和页脚入口。900px 及以下启用可键盘操作的移动菜单，Escape 先关闭资源子菜单，再关闭移动导航并返回触发按钮；无 JavaScript 时导航保持可见，资源菜单仍由原生 `details` 工作。

产品 Tab 支持方向键循环切换、Home／End、Enter／空格和可见选中状态；无 JavaScript 时三个面板全部展示，Tab 链接直接定位对应内容。指南目录在窄屏转入文档流；套餐卡片在窄屏改为单列，FAQ 和下载证据使用原生详情折叠。

各页共用可见焦点及明暗表面的对比规则。命令块保留原换行，在块内横向滚动，使用具名、可聚焦的区域以便键盘查看长命令；长 URL、哈希及正文允许断行，不靠隐藏整页溢出来掩盖问题。`prefers-reduced-motion: reduce` 关闭动画与过渡。首页组件样式按需输出，旧 `styles/showcase.css` 已由组件样式替代；产品图不裁切、不倾斜，也不用虚构界面填充缺失能力。

这些是源码实现范围，不是浏览器验收结果。合并后仍须在同一轮构建产物上检查：

- 六个路由在 **1920×1080、1440×900、768px、390px** 的实际布局，无非预期的文档级横向滚动；另核对 900／901px 导航断点两侧及 1024px。1440×900 首屏可见真实产品图；套餐卡片、长中文、URL、代码与哈希可读，命令的块内滚动不造成内容丢失。
- 六页的背景、字体、主按钮、导航与页脚使用同一视觉规则；页首、页脚和下载图标显示相同获批标志，图形比例与颜色保持不变；品牌首页链接有明确名称，邻接装饰图像不重复朗读；`/dovspace.svg?v=20261115`、`/favicon.svg?v=20261115` 实际可达，README 中的仓库相对素材可渲染。
- 从首个 Tab 到跳过链接，按 Enter 后焦点进入主要内容；继续用键盘经过资源菜单、移动导航、产品 Tab、指南目录、命令块、详情折叠和原图入口，焦点不被裁切，当前页面明确；禁用安装项不能触发或进入 Tab 序列。
- 核对核心文字／操作控件的 WCAG AA 对比度，自动工具无法判定的符号与焦点另作人工检查；减少动效偏好及无 JavaScript 降级生效。真实产品图能打开并放大阅读，替代说明、说明文字和素材来源对应，没有秘密或用户数据。
- 所有站内路径／片段、字体、图像和随附许可实际可达；外部源码／发行证据指向准确目的地；控制台和网络没有缺资源或浏览器错误；静态产物没有凭据、跟踪脚本或虚假公开 URL。

`pnpm typecheck:marketing`、`pnpm build:marketing` 与浏览器检查的实际结果应由集成人员另行记录；本页不把历史 P0 检查或源码存在写成本轮通过。更新工作包及合并检查单见 [Dovspace 宣传站更新计划](marketing-update-plan.md)。
