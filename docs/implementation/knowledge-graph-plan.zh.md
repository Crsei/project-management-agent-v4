# PM 知识关系图谱实施计划

状态：本文件记录初次 Canvas 力导向实现及其历史隔离验收。2026-11-02 展示层已迁移为 React Flow + ELK，当前实现与新批次证据见 [xyflow 关系图重构交付](xyflow-relationship-graph-plan.zh.md)；下述旧引擎、截图和测试结果不代表当前渲染器。授权、已保存事实、草稿隔离等数据合同继续有效。范围依据：现有 Markdown 核心上的 Obsidian 风格图谱；不迁移存储权威、不接入真实 Agent、不导入任意 Obsidian Vault。

## 1. 目标与边界

- 升级现有集合 Graph 视图，正式 `/pm/<workspace>/views` 可探索九类核心实体的正式关系、自定义引用与正文双链。
- 共享详情和完整实体页提供以当前实体为中心的局部图，支持一至三层邻域；知识图谱允许一般关联环，既有正式依赖防环语义不变。
- 力导向布局、缩放/平移、节点拖拽、类型着色、按连接数调整大小、邻居高亮、点击打开现有详情、搜索及关系类型筛选。
- 复用 Markdown、SQLite 可重建关系投影、现有授权和 SSE。正式图谱只展示已保存事实；存在草稿时明确提示，不把拖动坐标写成业务关系。
- 继续保留 React Flow + ELK 任务依赖图。采用 `react-force-graph-2d` 的 Canvas 渲染，不宣称 WebGL、万级容量或真实 Agent 执行已验收。

## 2. 数据与安全契约

- 在 `packages/pm-schema/graph.ts` 定义共享只读 GraphQuery/GraphData 和纯图查询；复用同一引用解析规则，稳定 ID 优先，名称歧义不得任选目标。
- GraphData 采用轻量节点和有类型有向边，不携带原文。正式引用与正文 link 保留独立类型；同源同目标同类型去重。
- 新增 `POST /api/v1/workspaces/:workspaceId/core/graph`，只读、`domain.read`，支持视图条件、搜索、归档、中心 ID、深度和关系类型。
- 先按完整工作区确定引用语义，再按当前权限裁剪；不能因隐藏同名节点而把歧义链接错误解析为可见节点。隐藏节点、关联和统计不得泄露；不可见中心与不存在中心使用相同拒绝语义。
- 未解析/歧义诊断仅在不泄露权限边界时返回。查询筛选之外的合法目标不冒充缺失链接。
- SSE 引发重新查询；身份/成员作用域变化、取消和请求乱序不能复活旧授权图数据。保存冲突继续走现有 revision 机制。

## 3. 执行分工

指定模型：`gpt-6.1-sol`，推理级别 `xhigh`。主代理冻结共享接口、管理依赖与锁文件、执行最终验证和记录证据。

| 工作包 | 文件责任 | 交付与验收 |
| --- | --- | --- |
| G01 图模型与授权接口 | pm-schema/graph、引用解析、pm-core、core-routes、相关合同和行为测试 | 类型边/双链、邻域、去重、歧义、过滤、权限隔离及真实 HTTP 行为 |
| G02 力导向视图 | pm-views 的图组件、替换旧 SVG Graph、组件样式 | Canvas 实际绘制；拖动/缩放/高亮/筛选/点击/无障碍导航；不修改业务数据 |
| G03 正式页面接入 | apps/web 的 Markdown client/controller/详情/集合及必要别名 | 正式集合、详情局部图、嵌入视图、SSE、草稿提示、授权错误、深浅主题及窄屏 |
| G04 集成与验收 | 主代理 | 依赖锁定、受影响检查、临时独立服务和真实浏览器操作、交付记录 |

代理禁止中途运行 build/lint/test/formatter，避免并行互相干扰；主代理在集成后统一运行。保留已有并行修改，不 commit 或 push，不停止既有服务。

## 4. 退出条件

1. 正式 Graph 显示来自真实临时服务的项目、任务、文档及类型边和正文双链，点击进入共享详情。
2. 当前实体局部图的一层与两层查询结果正确；关系类型筛选、搜索、归档和空态/失败态可解释。
3. 拖拽、缩放、平移、适配视口、邻居高亮、类型图例和连接数大小实际可用；浅色、深色及窄屏无横向溢出。
4. 保存 Markdown 后另一界面经 SSE 更新图谱；未保存草稿明确标记，不混入正式关系。
5. 受限主体不获得不可见节点、边、诊断或全局计数；不可见中心拒绝，歧义解析不受裁剪改变。
6. 有关图模型/权限/过滤边界的确定性行为测试通过；受影响 lint、类型检查、前后端构建及后端集成检查通过，无跳过冒充通过。
7. 记录实际浏览器与 HTTP 证据、性能/环境限制。清理自建验收资源，不修改用户工作区。

验收发现并修复了已有 Markdown SSE 的生命周期问题：API 普通连接空闲超时为 10 秒，而该 SSE 心跳为 15 秒；直连流在心跳前被终止。现仅对已授权 SSE 关闭普通空闲超时，并在 API `preClose` 主动结束订阅，保留原有心跳认证和成员范围复核。直连复验收到 `ready → change → heartbeat`，真实跨会话图谱同步和权限变化均已观察。
