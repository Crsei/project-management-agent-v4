# PM 目录型文档来源实施清单

状态：当前源码支持多目录关联和默认完整文件管理，现行边界及 API 合同见第一至三节；第四节起保留各历史批次的交付证据，旧“单目录／独立预检／外部只读”范围已被后续批次替代。范围为本仓库，未创建 PM 业务任务、未发布业务计划。会话与持久化尚未统一设计，继续沿用 Agent Chat；本次不调整聊天保存方式。

## 1. 目标与边界

- PM 文档页右上角“文档来源设置”隐含当前工作区，选择项目或“工作区公共文档”，浏览并关联多个后端可访问的已有目录，空目录也可选择。
- 递归发现该目录及子目录内所有普通 `.md` 文件（扩展名大小写不敏感），无需 PM frontmatter、ID 或标题。文件名与相对路径共同区分文件。
- 原有 PM 文档保持现有创建、编辑、revision 和详情入口；目录文件明确标识外部来源，不能伪装成 PM 实体或附件版本。
- 后端按需读取正文；页面提供安全 Markdown 预览及原地编辑。外部进程新增、修改、删除在进入页面或显式刷新后反映，不引入后台监听。
- 编辑、新建、移动、重命名、删除为现有授权下的默认能力，直接作用于外部文件；允许在已配置来源内创建缺少的父目录，绝不重建来源根。解除关联只修改配置，不删除文件、不修改其他关联、不遗忘未决操作；配置不改变 Agent cwd。
- 路径是后端机器的路径，不是浏览器电脑目录。一次确认执行实际目录检查与整组原子保存，不再单独预检；目录丢失或身份变化不回退、不重建。
- 同一路径可关联多个工作区／项目，仅同一关联范围内拒绝相同或互为父子的目录。工作区表格汇总所有授权来源，按不透明物理位置键去重，显示授权关联项目；同名／同正文但位置不同的文件仍独立。PM文档优先，项目筛选与操作使用该项目对应的来源。

## 2. 复用及安全约束

复用 `packages/application/src/agent-file-areas.ts`、`agent-storage.ts` 与本地目录的 allowedRoots/身份校验模式；复用现有认证、workspace/project ACL、目录管理能力，不新增权限体系。配置管理要求当前无限制工作区 access.manage、planning.edit 及实际读取能力；内容读取要求 domain.read 和对应关联范围，公共来源不对仅项目成员开放。主机绝对路径仅向可管理当前关联范围的主体披露。

每次配置、枚举、读取均检查当前授权及目录身份。拒绝路径穿越、绝对文件路径、软链接（含中间路径）、硬链接、特殊文件、越界和目录替换。明确关联的普通共享根不再整体排斥其他范围，但宽泛父目录仍过滤未授权的登记子树，核心／凭据／私有存储边界不变。未知文件操作按源、目标物理根阻止跨工作区及来源别名的重叠写入；缺少历史根证据时保守阻止写入，不根据查无收据猜测未执行。

列表分页必须可穷尽；扫描失败/安全排除/资源限制不能伪装成完整或空列表。大文件读取按现有文件大小保护明确拒绝，不静默截断正文。Markdown 使用已有安全渲染机制，禁止原始 HTML/脚本及越界相对资源请求。INV-01/20、SC-14/20、INF-01/04/05/06 为相关隔离、权威读取、持久化与合同依据，不改变旧业务完成规则。

## 3. 共享 HTTP/TypeScript 合同

合同归 `packages/contracts/src/document-sources.ts`；前端复用同一合同。路径均在 `/api/v1/workspaces/:workspaceId/document-sources` 下，复用 PM Cookie/Bearer 和 Origin 校验，响应 private/no-store。`sourceId` 是来源实例的不透明标识，不能再从项目 ID 推断来源；新关联使用 UUID，历史来源标识通过迁移保留。

- GET 基础路径：`{ sources, scopes }`；来源只含有效关联，可选择范围独立列出，未关联目录的授权项目仍可选择。
- GET `/directories?path=...&projectId=...`：受限服务端目录浏览器；省略 projectId 表示公共范围。只列已有目录，不创建目录。
- PUT `/configuration`：`{ projectId, expectedRevision, paths: string[] }`，返回 `{ scope, sources }`。整组 CAS／目录检查在同一事务内完成；一项无效则全部不保存。保留未变目录的 sourceId／来源 revision，删除项留可恢复墓碑，空数组解除该范围全部关联。
- GET `/:sourceId/files`：可选 cursor／limit，返回条目、分页及扫描状态；条目包含工作区内不透明 `fileKey`，不暴露绝对路径或跨工作区可关联标识。
- GET `/:sourceId/content?path=...`：读取该授权来源内的相对路径，正文含来源及文件 revision。
- POST `/:sourceId/operations`：create/save/move/delete；移动目标字段为 `targetSourceId`。GET `/:sourceId/operations/:operationId` 只核对原操作，不重放。

旧 `/preview` 和单来源 PUT 已删除。迁移 `0045_document_source_associations.sql` 保留历史请求／收据 JSON 及其哈希、主体授权范围和持久完成证据；内部解释历史字段不构成旧 HTTP 别名。浏览器旧标签和操作日志在读取边界迁移，原 operationId 保留，损坏日志不能静默清除未知阻塞。

配置响应未知先 GET 比较整组目录及版本；文件操作响应未知保持原编号。分页每次重读清空旧游标，任一页失败不能冒充完整快照，安全排除仍显示不完整。具体字段以共享 schema 和生成 OpenAPI 为准，避免重复维护类型副本。
