# 产品规划工作台：需求引导、多任务 Roadmap 与集成预览

日期：2026-11-02。复用 Markdown 核心、项目授权、任务与交付工作流；不是恢复 v3 的完整执行计划，也不新增角色或业务完成规则。遵循 INV-01/03/13/14/15/20、SC-12/13/14/17、Markdown ADR。

## 使用路径（2026-11-04 收敛为画布）

项目导航进入「产品规划」，默认展示一张产品画布，不再提供明确产品 / 规划路线 / 交付与验收三个分离工作台。

1. **编辑 PRD → 从 PRD 生成画布**：在弹窗填写产品目标、用户、需求、非目标、共享约定与验收；选择现有 Provider / 模型生成结构化候选，确认应用后回到画布。候选不自动创建任务或启动开发。
2. **点击节点编辑任务**：草稿节点编辑名称、需求成果、验收、非目标、阶段与依赖；位置可拖动。运行后节点打开其真实任务详情；运行中只读，暂停后修改会触发需求漂移检查，不会静默继续旧需求。
3. **运行画布**：集中确认冻结版本、创建任务、Agent 执行、worktree 写入、提交、推送、Draft PR 和状态联动。提交与推送保留各自勾选项，未授权不启动。前端保存草稿并发布不可变版本；后端按拓扑序建立或复用任务，一次只派发一个节点；前一节点测试与当前 HEAD CI 验证后，后续节点继承其分支，形成同一个 App。
4. **查看产品**：复用项目集成证据和隔离预览入口；画布交付验证不是业务完成，不自动合并、部署、审核通过或关闭任务。

主画布只暴露需求、节点、运行进度与产品入口；版本冲突核对及 Git 细节放在详情中。原本机草稿和 Agent 候选记录继续保留，不以演示内容覆盖。

## 数据与一致性

- 草稿与发布版本保存在项目 Markdown 的 `x-pm-product-roadmap`，发布内容不可通过常规核心修改覆盖或删除；`x-pm-roadmap-origin` 固定真实任务来源。阶段仅为规划分组，不冒充业务 Milestone 对象。
- 应用层拥有计划发布检查、任务输入和来源投影；HTTP 使用既有当前授权、工作区SQL锁、文件CAS、原生命令journal/收据、审计和事实捕获。没有数据库迁移，也不引入第二个任务事实源。
- 同一版本/节点的创建键固定，核对原收据；并发跨用户通过串行守卫再次检查来源，不能重复创建。删除/缺失来源不能被当作从未创建，已归档/需求偏离的前置不被静默复用。
- 草稿写入要求项目revision；并发变化不覆盖。响应不明时保留原请求并冻结编辑，先刷新读取真实版本与任务映射，再明确载入服务端内容，不自动重放。发布与创建均不自动转换任务状态。
- 本机未保存草稿按origin/actor/workspace/project分区，离页提示；没有统一跨设备草稿同步。持久化失败明确提示；服务端不可读时不显示为可编辑。
- 最大24节点、20个发布版本；不生成工期、预算或负责人承诺，画布 DAG 按拓扑序串行推进，不做并行分支自动合并。GitHub 授权在运行入口分别勾选，仅覆盖冻结版本和绑定仓库；本功能不批准或合并 PR。

## 运行与安全边界

现有单任务预览与项目预览运行同一已提交候选，项目入口额外要求全图提交覆盖证据；并非新建公网服务。只读Chat权限不变，开发只在绑定worktree。CI缺失、过期需求、不兼容仓库、前置代码未包含、未知操作等均保持未就绪；不以假数据或手动勾选覆盖。

会话与持久化尚未统一设计，仍沿用 Agent Chat 基础存储。本次显式划定项目规划源、任务来源、浏览器草稿和既有Agent交付记录的边界，不宣称统一会话设计收口。

## Agent 直接生成候选（2026-11-03）

本轮是降低操作成本的第一步，不是项目级自动执行器。项目简报/工作区详情页新增「产品规划」入口。规划页无需复制提示词和粘贴JSON：明确选择Provider后生成，结果进入独立审阅区；确认后只替换本机草稿节点，不修改PRD、发布版本或真实任务。随后沿用画布编辑、保存和发布流程。

- 输出严格限制为summary/questions/nodes，校验字段、大小、唯一编号、依赖引用和无环。未决问题非空时不允许应用。结构合法不等于业务合理，仍需人工核对。
- 冻结输入草稿与项目revision；生成期间手动编辑或版本改变，拒绝覆盖。审阅区提供原草稿与候选的成果、验收、非目标及前置关系。
- 网络写入前保存请求ID和输入快照，刷新后只核对原会话，绝不自动重发。显式结束使用既有消息取消记录，防止迟到请求再次执行。
- 未就绪Provider不回退规则结果；失败、中断、取消、格式错误不应用候选。既有规则生成保留为明确标注的备用入口。
- 会话与持久化仍沿用Agent Chat，本机恢复按origin/actor/workspace/project分区；不宣称统一设计或多标签页全局互斥已完成。
- 尚未实现：项目级授权后的阶段自动调度、自动多前置集成、合并或部署。发布计划不是构建授权。

定向规划回归11项通过（含新增6项），Web lint/TypeScript/Vite构建通过，保留既有大chunk警告。完整pnpm check仍在root不可写目录测试失败，不标记全绿；实际Provider与浏览器结果另行记录。
