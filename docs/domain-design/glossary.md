# 领域术语

> 适用性：本文件保留v0.1历史提案/稳定编号，不代表完整业务Runner或旧SQL核心规则已启用。当前Markdown任务状态、审核独立性与关系语义以[已采纳ADR](../architecture/adr/0003-markdown-core.md)及[入口第七节](README.md#implementation-plan)为准；Chat thread/generation不能替代历史Session/Run模型。

本文件服从 [版本与提案范围](README.md)。英文名是契约中的规范概念名；中文用于产品交流。相同英文名在不同模块不得暗含不同生命周期。

| 术语 | 定义 | 不应混同 |
| --- | --- | --- |
| Workspace（工作空间） | 数据隔离、成员身份和授权的顶层作用域 | 不是本地目录、Git worktree 或 Agent 进程 |
| Principal（主体） | 可识别的用户、Agent 或服务身份 | 不是自然语言中自称的“管理员” |
| Conversation（对话） | 围绕问题持续交流的记录，可关联项目 | 不是执行 Session；消息不自动成为承诺 |
| Intent（意图） | 从讨论中提出、可接受或拒绝的需求候选，包含目标与来源 | 不是已经排期的 WorkItem |
| Decision（决策） | 有决策人、理由、时间及依据的不可变决定记录 | 不是 Agent 的推测；新决定通过替代关系修正旧决定 |
| Project（项目） | 围绕共同目标组织工作、里程碑与完成判断的业务容器 | 不是代码仓库或 Session |
| WorkItem（工作项） | 可分派、追踪、提交成果并验收的一项工作承诺 | Task、Issue 在本版是它的别称，不另设实体；不等同 Run |
| AcceptanceCriterion（验收标准） | 可检查的工作成果条件，属于工作项内容版本 | 不是模型自行输出的“已完成” |
| Milestone（里程碑） | 项目内有目标日期和达成标准的阶段性检查点 | 不是 Cycle/Sprint，也不是百分比统计 |
| Dependency（依赖） | 工作项指向前置工作项的有向关系 | 不是父子关系；取消前置项不自动解除依赖 |
| Session（执行会话） | 某项目中可持续多个 Run 的执行上下文 | 不是 Project 或 Conversation；可以引用对话作为输入 |
| Run（运行） | 一次有明确输入快照、执行主体和生命周期的尝试 | 不是业务工作项；每次重试有新 RunId |
| Approval（动作审批） | 对特定运行中某个动作及参数的限时授权决定 | 不是成果验收；同意执行不表示认可执行结果 |
| OperationReceipt（操作凭据） | 记录外部动作的稳定标识、派发及结果证据的执行记录 | 不是批准书，也不是外部副作用必然成功的证明 |
| Artifact（成果） | 具有稳定身份的交付物，如文档、补丁、构建物或文本说明 | 不是一次运行的状态；仅有 URL 不足以锁定内容 |
| ArtifactVersion（成果版本） | Artifact 的不可变内容版本或不可变外部引用及摘要 | 不使用可变分支名或“latest”作为验收对象 |
| Evidence（证据） | 指向版本化成果或执行事实的观察记录，带方法、范围、结果和来源 | 测试成功只证明该测试范围，不自动证明业务验收 |
| Submission（交付提交） | 工作项某内容版本的一组固定成果版本与证据引用 | 不是 Git commit；不一定来自 Agent |
| Review（成果审核） | 人对某一 Submission 及其验收标准的结论 | 不是 Approval，不自动完成工作项 |
| Command（命令） | 某主体请求业务改变的意图，可能被拒绝 | 接收命令不表示业务已成功提交 |
| Domain Event（领域事件） | 所属模块已经提交的事实，使用过去式命名 | 不是命令、日志文本或供应商未经验证的通知 |
| Policy（业务策略） | 在给定事实下决定是否提出后续命令的规则 | 不是事件处理器任意修改其他模块数据的许可 |
| Aggregate（聚合） | 维护一组一致性约束的业务边界，通过聚合根修改 | 不是每张表都独立成为聚合，也不是把全项目装进一个对象 |
| Projection（读模型） | 由事实派生的列表、看板、统计或时间线 | 不是授权和完成判断的权威来源 |

## 状态与版本用语

- `succeeded` / `failed`：描述 Run 的执行结果。`done`：工作项经过业务验收后的完成状态。
- `outcome_unknown`：无法确定外部执行结果，需要核对；既不判成功，也不判失败。
- `cancel_requested`：已请求停止，仍需确认外部执行已停止；不等于 `cancelled`。
- `blocked`：由未满足依赖或显式阻塞原因构成的工作项属性，不是 Run 失败的同义词。
- `version`：聚合每次修改递增的并发版本。`contentRevision`：工作项范围和验收标准的业务版本，仅内容变化递增。
- `correlationId`：连接同一业务流程；`causationId`：指向直接触发本次事件的命令或事件。二者都不承担去重职责。
- `archivedAt`：归档标记。归档保留对象及历史，不代表成功、取消或删除。

尚未纳入本版的 Initiative、Cycle、Sprint、RiskRegister 不得仅因参考产品存在而自动引入模型。
