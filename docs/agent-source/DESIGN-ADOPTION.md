### 状态三轴（提案「三条状态轴」在本项目的落点）

| 轴          | 本项目表达                                                                                                                                                                                                                       |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Interaction | hover = `--sidebar-accent` 弱底色；selected = 同底色 **+ 左侧 2px 品牌色持久标记 + 字重 500**；focus = accent 色 2px 焦点环；expanded = 折叠箭头旋转 + `data-open` 面板                                                          |
| Data        | 加载 = 线程骨架（`ThreadHistorySkeleton`、线程列表骨架）；空 = 欢迎语 + 建议词；局部错误 = `ErrorPrimitive` 错误条（不覆盖已有内容）                                                                                             |
| Runtime     | 运行中 = 工具/推理条目仅有活动提示（spinner + shimmer 文字 + 耗时）；结束项静止并给出结果文字（“Used tool / Failed tool / Cancelled tool”）；等待用户决定 = “Waiting on tool” + 强调图标，且不显示为已完成；未知原因不显示为成功 |

### 动效（提案「动效分工」）

hover/颜色 150ms ease-out（不改布局尺寸，按下反馈用 `scale` 而非位移）；菜单/Dialog/折叠 200ms 减速曲线；运行提示只出现在运行中的条目；`prefers-reduced-motion` 下用 `motion-reduce:` 关掉循环与位移动效。
