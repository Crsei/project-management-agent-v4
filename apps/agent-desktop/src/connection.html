Connection mode
The Server runs here. Choose an existing project folder; changing mode never moves your files.
Uses this v3 checkout’s .local/agent-data (or packaged v3 app data), never the old global Agent directory. Only one Server may own it. Use the public v3 connection for PM scope/catalog features.
Use “node” from PATH, or an absolute executable path. Native PTY runs in Node, not Electron.
HTTPS is required outside loopback. Use the server origin, not an API URL or a URL containing an access token.

You will sign in on the Server’s workspace login page. Remote sessions are isolated from the local Server and its private access token. Trust the Server before entering credentials.
