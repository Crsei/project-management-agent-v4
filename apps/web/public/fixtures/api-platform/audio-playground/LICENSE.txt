Audio Playground fixture media

The six WAV files in this directory are original synthetic speech recordings generated offline for EasyuseUI on 2026-10-13. Their short scripts reproduce the reference demo scenarios and are in packages/agent-workspace-views/api-platform/audio-playground/fixtures.ts. No Shadcnblocks audio, human recordings, external provider output, or cloned voices are redistributed.

To the extent copyright exists in these generated recordings, they are dedicated to the public domain under CC0 1.0 Universal (SPDX: CC0-1.0): https://creativecommons.org/publicdomain/zero/1.0/ . This dedication does not change rights in reference UI wording.

Generator: eSpeak 1.48.04+dfsg-5 (Ubuntu bionic package), using its built-in en and es synthetic voices. The tool is GPL-3.0-or-later and is not distributed here. Its license states that program output is covered only when the output itself constitutes a covered work: https://espeak.sourceforge.net/license.html . These WAV files contain original rendered speech, not the eSpeak program or voice database. Generation uses only fixed scripts and happens offline; the running application does not perform speech synthesis.

Reproducibility: generate-media.mjs accepts the local eSpeak executable and its data-directory parent via ESPEAK_BIN and ESPEAK_DATA_PARENT, writes mono PCM 16-bit WAV files, measures exact durations, and derives 96 waveform peaks from the generated samples. Clear voice uses en/es, 185 words/minute, pitch 52; warm voice uses en, 155 words/minute, pitch 36.
